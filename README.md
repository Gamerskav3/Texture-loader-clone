# Texture Loader Clone

Load texture packs in Geometry Dash 2.2081 (Geode 4).

1. Open the Texture Packs button on the main menu (bottom menu).
2. Put packs (folders or .zip) in the `packs` folder inside this mod's config folder.
3. Toggle packs on, move them up/down (top = highest priority), press Apply, restart the game.

A pack = a folder with files named like the game's Resources (e.g. `GJ_GameSheet03-uhd.png`), either at the root or in a `resources` subfolder. An optional `pack.json` with `id`, `name`, `version` is supported.
